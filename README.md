# Jansakshi AI

An AI-powered platform designed to provide citizen services, data insights, and intelligent assistance.  
This project integrates modern AI techniques with a user-friendly interface to make information more accessible.

---

## 🚀 Live Demo
[Click here to try Jansakshi AI](https://jansakshi-ai.vercel.app)

---

## ✨ Features
- AI-powered query handling for citizens
- Data visualization and insights
- Secure authentication and role-based access
- Responsive frontend for mobile and desktop
- Scalable backend with database integration

---

## 🛠 Tech Stack
- **Frontend:** React.js  
- **Backend:** node js / express js 
- **Database:** PostgreSQL / SQLite  
- **Deployment:** Vercel / Netlify / GitHub Pages  
- **Version Control:** Git & GitHub
